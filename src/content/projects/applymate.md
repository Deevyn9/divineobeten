## Overview

ApplyMate is a personal productivity tool built specifically for engineers navigating active job searches. Designed and built entirely by me, it brings structure and visibility to the application process without the noise of generic project management tools.

## What I Built

I owned everything — product thinking, design, and engineering — building ApplyMate entirely from scratch.

**Application Logging**
Built the core feature — a form to save application details including job title, company, link, date applied, and notes. Every application is stored and retrievable with full detail.

**Table View & Status Tracking**
Built a clean table interface displaying all logged applications with inline status updates. Users can move applications through stages — Applied, Interview, Offer, Rejected — without leaving the table.

**Streak Feature**
Built a streak system that tracks consecutive days of applications, encouraging consistency during the job search. The streak resets if a day is missed, adding a light layer of accountability.

**Activity Calendar**
Built a GitHub-style contribution calendar that visualises application activity over time — giving users a bird's eye view of their job search momentum across weeks and months.

**Search & Filtration**
Built search and filter functionality allowing users to find applications by job title, company name, status, and other parameters — useful when managing a large number of active applications.

**Auth System**
Built full authentication — signup, login, session management — so data is tied to individual user accounts and persists across sessions.

**Design**
Designed the entire product myself — dark-themed UI with a focus on clarity, data density, and a polished feel that goes beyond a typical utility tool.
