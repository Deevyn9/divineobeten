## Overview

TravelMoods is a personal project inspired by Marc Lou's MovieMoods concept — instead of movies to match your mood, it suggests places to travel to. Pick a mood, get a destination, watch a YouTube preview of what it actually feels like to be there.

## What I Built

### Mood-to-Destination Engine

Built a comprehensive JSON dataset mapping moods to travel destinations — each entry includes the destination name, associated moods, and an embedded YouTube link capturing the feel of that place.

### Mood Selection UI

Designed and built the mood selection interface — clean, intuitive, and fast. Users pick how they're feeling and instantly get curated destination suggestions that match.

### YouTube Preview Integration

Embedded YouTube previews for each destination so users can get a feel for a place before committing to the idea. The visual and emotional context makes the suggestions feel real, not just a list of names.

## Outcome

A live personal project that turns a simple mood into a travel inspiration moment — combining a clean UI with a hand-curated dataset to make destination discovery feel personal and immersive.
