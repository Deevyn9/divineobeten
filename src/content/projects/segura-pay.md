## Overview

SeguraPay is a Banking-as-a-Service platform designed to provide comprehensive banking functionalities to corporate clients through a secure and scalable API-first architecture. The platform enables businesses to integrate banking services directly into their operations — including account management, payments processing, and financial transactions.

## What I Built

As founding frontend engineer, I owned the entire frontend across three user roles — Admin, Corporate Admin, and Corporate User.

**Authentication & Onboarding**
Built all auth pages including login, forgot password, and a custom flow that routes admin-created users directly to a password creation page on first access. Implemented a live password validation feature with real-time feedback as users type.

**Dashboards**
Designed and built three separate dashboards tailored to each user role — each with its own data hierarchy, navigation structure, and permission scope. The Admin dashboard provides platform-wide oversight, Corporate Admin manages their organisation, and Corporate User handles day-to-day operations.

**User & Role Management**
Built a full RBAC system allowing admins to create users and assign granular roles and permissions at the point of creation. Built the complete user management interface including listing, filtering, and user detail views.

**Payments & Wallet**
Built the payment overview interfaces and wallet management features across both admin user types — covering balance views, transaction histories, and transfer flows.

**Checking System**
Built and onboarded a checking system from scratch, integrating the relevant APIs and building the UI flows around it.

**Settings & Admin Features**
Built user settings pages and admin-specific management features, ensuring consistent experience across all three user types.

**API Integration**
Integrated backend APIs across every feature — handling data fetching, error states, loading states, and edge cases throughout.

**Interactions & Polish**
Delivered seamless transitions and interactions across the platform, ensuring the product felt considered and production-ready beyond just being functional.
