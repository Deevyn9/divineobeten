## Overview

AtWork streamlines the freelance hiring process, providing businesses with instant access to a network of skilled professionals. The platform enables seamless collaboration, efficient project management, and on-chain accountability for both freelancers and hirers.

## What I Built

I took ownership of the entire frontend — rebuilding the app from scratch based on new designs and integrating all APIs outside of auth.

**App Rebuild**
Rebuilt the complete frontend based on updated designs, translating Figma files into a fully functional, production-ready interface while maintaining design fidelity throughout.

**Onboarding**
Integrated the onboarding APIs and built the corresponding UI flows for new users entering the platform.

**Bounty System**
Built the full bounty lifecycle — creation forms, bounty discovery and listing, application flow for freelancers, task submission interfaces, submission review for hirers, and winner assignment. Every step of the on-chain bounty process has a corresponding UI I built and wired to the API.

**Gig System**
Built the complete gig workflow — gig creation, listing and discovery, freelancer application flow, and hirer-side applicant management including selecting who works on a gig.

**API Integration**
Connected all bounty and gig APIs end-to-end — handling request states, response mapping, error handling, and edge cases across every flow.

## Outcome

Delivered a fully functional on-chain bounty and gig marketplace connecting freelancers to hirers, with complete frontend ownership from UI rebuild through API integration.
